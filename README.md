# Fitness Plan — Mohanad | خطة اللياقة

تطبيق يومي لتنفيذ خطة اللياقة: افتحه كل يوم، سجّل الأرقام، واضغط «حفظ اليوم». البيانات تُحفظ في Supabase خلف تسجيل الدخول.

**الرابط:** https://maz1988sa-tech.github.io/fitness-plan/

- **اليوم:** الوزن والنوم والوجبات والسوائل والخطوات والكارديو والمكملات، مع مواعيد اليوم (InBody، الخصر، الصور، اختبار اللياقة).
- **التمرين:** حصة اليوم بمجموعات الأسبوع الحالي، و«آخر مرة» لكل تمرين، وتلميح التدرج المزدوج، ومؤقت الراحة.
- **التقدم:** متوسطات الأسابيع، مخطط الوزن مقابل المسار المخطط، واقتراح جدول القرار من الأسبوع 3.
- **الخطة:** نص الخطة كاملًا كما في المستند.

لا يحوي هذا المستودع أي بيانات شخصية؛ التفاصيل التقنية والقرارات في `CLAUDE.md`.
